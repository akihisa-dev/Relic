# リンクとタグの仕様

内部リンク、バックリンク、タグ機能の詳細仕様書。
`[[...]]` リンク、バックリンク一覧、フロントマター `tags:` による整理、入力補完など、ファイル間の接続に関わる振る舞いを定義する。

---

## 内部リンク `[[...]]`

- リンクの対象は現在開いているワークスペース内のファイルのみ。複数ワークスペース間のリンクは非対応。
- `[[ファイル名]]` 記法でファイル間を接続する内部リンクを作成する
- パスを含まない `[[ファイル名]]` は、リンク元ファイルと同じフォルダの既存ファイルを優先して解決する。同じフォルダに存在しない場合でも、ワークスペース内で同じファイル名のMarkdownが1つだけなら、そのファイルへ解決する
- リンク先ファイルが存在しない場合：
  - リンクとして表示しつつ、色や下線などのスタイルで「未作成」であることを示す
  - クリックすると自動で新規ファイルを作成し、そのファイルを開く（作成場所：リンクが書かれているファイルと同じフォルダ）
- `[[` を入力した時点で、ファイル名のオートコンプリートをカーソル直下にドロップダウンリストで表示する
- パス指定 `[[フォルダ名/ファイル名]]` の書き方をサポートする（手打ち・補完どちらも可）
- 同じファイル名が複数フォルダに存在する場合、補完候補に `フォルダ名/ファイル名` の形式で両方を表示し、ユーザーが選択する。選択したリンクはパス付き `[[フォルダ名/ファイル名]]` で挿入される

## Markdownリンク `[text](...)`

- Markdown標準の `[テキスト](リンク先)` は、リンク先が相対Markdownパス、または `/` 1文字から始まるワークスペースルート基準のMarkdownパスの場合に、ワークスペース内ファイルとして開く
- 相対Markdownリンクはリンク元ファイルのフォルダを基準に解決し、`/folder/file.md` はワークスペースルートを基準に解決する
- リンク先に `.md` 拡張子がない場合は、Markdownファイルとして `.md` を補って解決する
- リンク先に `#見出し` が含まれる場合は、ファイルを開いたあと指定見出しへスクロールする
- ワークスペース内Markdownリンクの対象ファイルが存在しない場合は、新規Markdownファイルを作成して開く
- 外部URL、プロトコル付きURL、`//` から始まるパス、ページ内アンカーだけのリンクは、ワークスペース内ファイルとして開かない

### 対応する記法バリエーション

| 記法 | 動作 |
|------|------|
| `[[ファイル名]]` | ファイルを開く |
| `[[ファイル名\|表示テキスト]]` | 表示テキストを変えてファイルを開く |
| `[[ファイル名#見出し]]` | ファイルを開き、指定した見出しの位置にスクロール |
| `[[ファイル名^ブロックID]]` | ファイルを開く。ブロックIDは解析するが、指定位置への自動スクロールは行わない |
| `[表示テキスト](相対パスまたは/ルート基準パス)` | 相対Markdownパスはリンク元基準、`/` 始まりはワークスペースルート基準で解決してファイルを開く |
| `![[ファイル名]]` | ファイルの内容をその場に展開して表示（埋め込み） |

### ブロック参照について

- ブロックIDは段落末尾に `^abc123` のような形式で手入力できる
- 現行UIには、ブロックIDを自動生成して挿入する常時表示ボタンはない
- 既存の手書きIDはリンク情報とリネーム追跡の対象として読み取り、右パネルにも表示する。現行実装では指定ブロックへのジャンプには使わない

### ファイル埋め込みについて

- `![[ファイル名]]` は一段階だけ展開表示する
- 埋め込み先のパスは、埋め込み元ファイルのフォルダではなくワークスペースルートを基準に解決する
- 埋め込み先の本文にさらに `![[...]]` があっても、その内側の埋め込みは展開しない
- 大きすぎるファイルは全文表示せず、大きすぎることを示す通知を表示する
- 埋め込み内リンクは通常の内部リンクと同じように開く
- 埋め込み内では直接編集せず、編集する場合は元ファイルを開く

## バックリンク・アウトゴーイングリンク

- バックリンクとアウトゴーイングリンクの集計対象は `[[...]]` と `![[...]]` だけとし、Markdown標準の `[text](path.md)` は含めない
- **バックリンク一覧**：そのファイルを参照しているファイルの一覧
- **アウトゴーイングリンク一覧**：そのファイルが参照しているリンクの一覧
- **未リンク参照一覧**：そのファイルの拡張子なしファイル名が、内部リンクではない通常テキストとして本文に出ている箇所の一覧
- バックリンク・アウトゴーイングリンクはナビゲーション補助として位置づける
- 両一覧ともに、右パネル（アウトラインパネルと同じ領域）に表示する
- エクスポートの対象には含まれない
- アウトゴーイングリンクでは、通常のWikiリンクと埋め込みリンクを種別ラベルで区別して表示する
- アウトゴーイングリンク先が存在しない場合は、未作成として表示する
- アウトゴーイングリンクに見出しやブロックIDが含まれる場合は、リンク先名とは別に `#見出し` や `^ブロックID` を表示する
- アウトゴーイングリンクは最大1,000件まで表示し、上限を超えた場合は一部のみ表示していることを示す
- バックリンクでは、参照元ファイル名を表示し、同じ参照元から複数回リンクされている場合は件数を表示する
- バックリンク読み込み中は読み込み中表示を出す
- バックリンク一覧の読み込みに失敗した場合は、バックリンク一覧を空にし、エラー内容をトースト通知として表示する
- 未リンク参照はバックリンクの下に表示する
- 未リンク参照では、参照元ファイル名、行番号、該当行を表示する
- 未リンク参照の候補は1件ずつリンク化できる
- リンク化では、該当文字列だけを内部リンク記法へ置き換える
- 同名Markdownファイルが複数あり、`[[ファイル名]]` では対象ファイルへ解決できない場合は、表示文字列を保つため `[[フォルダ/ファイル名|ファイル名]]` の形式でリンク化する
- 既存の `[[...]]` / `![[...]]` 内、Markdown標準リンク内、コードブロック内の文字列は未リンク参照候補にしない
- 未リンク参照のリンク化時に参照元ファイルが外部で変わっている場合は、リンク化せず再読み込みを促す
- 未リンク参照は最大500件まで表示し、上限を超えた場合は一部のみ表示していることを示す
- 右パネルのリンクは右クリックメニューを持ち、開く、分割表示中の別ペインで開く、Markdownリンクをコピー、パスをコピー、OS上の場所を表示できる
- バックリンク集計中に一部の参照元Markdownファイルを読めない場合は、そのファイルだけをスキップして一覧を表示する
- アウトゴーイングリンクには、通常のWikiリンクとファイル埋め込みリンクの両方を表示する

## タグ

- タグはフロントマターの固定プロパティ `tags:` に記述する
- 本文中の `#タグ名` 記法はタグとして扱わない
- 本文中で概念・人物・資料などを参照する場合は、インラインリンク `[[...]]` を使う
- タグは内部検索処理と各ビューの絞り込みに利用する。内部検索処理には現行UIから検索語句を自由入力する導線を接続していない
- **階層タグをサポート**：`親/子` の形式で `/` によるネストが可能（例：`キャラ/主人公`）
- **日本語タグをサポート**：日本語・漢字・ひらがな・カタカナを含むタグ名が使用可能
- タグ入力時は、ワークスペース内の既存 `tags:` から候補を出し、表記揺れを抑える
- タグ一覧集計中に一部のMarkdownファイルを読めない場合は、そのファイルだけをスキップして一覧を表示する
- 共有ワークスペースグラフでは、可視化専用の派生データとして本文中の `#タグ名` もタグノードにする。ただし、通常のタグ一覧・タグ検索・タグ入力候補には使わない
- バブルビューとスフィアビューは共有ワークスペースグラフから実在するMarkdownファイルだけを固定条件で表示し、未解決リンクは表示対象に含めない。リンクの解決結果や座標をMarkdown本文へ書き戻さない
