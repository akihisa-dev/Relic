# ファイル加工ツール仕様

ファイル加工ツールの仕様書。既存ファイルを変更せず、結果は必ず新規ファイルとして出力する。

**原則：既存ファイルは読み取りのみ。操作の結果はすべて新規ファイルとして作成する。**

現行UIは設定画面を持たず、右クリックした対象に対して4種類の加工をそれぞれ既定値で直ちに実行する。以下では、通常操作で使われる既定動作と、Main側が受け付ける構造化入力の能力を区別して記載する。

---

## フォルダ内マージ

右クリックした対象のファイルを1つのファイルに結合して出力する。通常操作では絞り込みを追加せず、ファイル名順で結合し、各ファイル名の見出しを挿入する。

- Main側の構造化入力では、絞り込み条件としてタグ・フロントマターのフィールド値・フォルダ・すべてを受け付ける
- 絞り込み条件の既定値は「すべて」とする
- フロントマター絞り込みでは、フィールド名と値を指定する（例：`category` が `draft` のファイルだけ）
- タグ絞り込みでは、入力値の先頭に `#` があってもタグ値として扱う
- フロントマター値が真偽値の場合、`true` / `false` のほか、`1` / `0`、`yes` / `no`、`on` / `off` でも照合できる
- Main側の構造化入力では、結合順序としてファイル名順・更新日時順・作成日時順を受け付ける
- 結合順序の初期値はファイル名順とする
- ファイル名順はワークスペース相対パスの昇順、更新日時順と作成日時順は新しい順とする
- Main側の構造化入力では、各ファイルの区切りとしてファイル名を見出しに挿入するかどうかを指定できる
- ファイル名見出しの挿入は初期状態でオンとする
- ファイル名見出しを挿入する場合、各ファイルの直前に拡張子を除いたファイル名をH1見出しとして入れる
- 結合時は各ファイル本文の前後空白を取り除き、ファイル間は水平線 `---` で区切る
- Main側の構造化入力では出力先フォルダとファイル名を指定できる。通常操作ではワークスペースルートと既定名を使う
- 出力ファイル名が空の場合は、既定名「マージ結果」を使う
- 出力先に同名ファイルが存在する場合は上書きせず、別名で保存する
- 絞り込み候補を作る段階で読めないMarkdownファイルがある場合は、その候補だけを除外して続行する
- 結合対象として確定したファイル本文を読み込めない場合は、安全側で処理を失敗させる

---

## タイトル一覧

右クリックした対象のファイル名をリスト化して新規ファイルに出力する。

- 対象は右クリック位置と複数選択から決まり、別のフォルダ条件やタグ条件は適用しない
- Main側の構造化入力にはフォルダ・タグ条件用の項目があるが、タイトル一覧生成処理では使用しない
- Main側の構造化入力では、並び順としてファイル名順・更新日時順を受け付ける
- 並び順の初期値はファイル名順とする
- ファイル名順は拡張子を除いた表示名の昇順、更新日時順は新しい順とする
- 出力形式：箇条書き（内部リンク付き）
- 例：`- [[ファイル名]]`
- 同じファイル名のMarkdownがワークスペース内に1つだけの場合は、拡張子を除いたファイル名だけの短い内部リンクにする
- 同じファイル名のMarkdownがワークスペース内に複数ある場合は、`[[./フォルダ/ファイル名|ファイル名]]` のようにワークスペースルートからのパスを含め、対象ファイルを一意に指すリンクにする
- リンクの表示名は、拡張子を除いたファイル名だけを使う
- Main側の構造化入力では出力先フォルダとファイル名を指定できる。通常操作ではワークスペースルートと既定名を使う
- 出力ファイル名が空の場合は、既定名「タイトル一覧」を使う
- 候補作成中に一部のMarkdownファイル情報を取得できない場合は、その候補だけを除外して続行する

---

## 目次生成

右クリックした対象のファイルを内部リンク一覧として出力する。フォルダの索引ファイルとして使える。

- 対象は右クリック位置と複数選択から決まる。フォルダを対象にした場合は子フォルダを含む配下を再帰的に扱う
- 出力形式：フォルダ階層を反映したネストリスト（内部リンク付き）
- 目次内ではフォルダをファイルより先に並べ、同じ階層内では名前順に並べる
- フォルダ行は `**フォルダ名/**` として表示し、ファイル行は内部リンクとして表示する
- 同じファイル名のMarkdownがワークスペース内に1つだけの場合は、拡張子を除いたファイル名だけの短い内部リンクにする
- 同じファイル名のMarkdownがワークスペース内に複数ある場合は、`[[./フォルダ/ファイル名|ファイル名]]` のようにワークスペースルートからのパスを含め、対象ファイルを一意に指すリンクにする
- リンクの表示名は、拡張子を除いたファイル名だけを使う
- Main側の構造化入力では出力先フォルダとファイル名を指定できる。通常操作ではワークスペースルートと既定名を使う
- 出力ファイル名が空の場合は、既定名「目次」を使う
- 既存の目次ファイルは自動更新しない
- 出力先に同名ファイルが存在する場合は、別名で新規作成する
- 子フォルダの走査中に一部の子フォルダを読めない場合は、その子フォルダだけを除外して続行する
- 対象フォルダ自体が読めない場合は、安全側で処理を失敗させる

## タグ別索引

右クリックした対象について、フロントマター `tags` をもとにタグごとの内部リンク一覧を新規ファイルに出力する。

- 対象は右クリック位置と複数選択から決まる。フォルダを対象にした場合は子フォルダを含む配下を再帰的に扱う
- Main側の構造化入力では、タグなしファイルを含めるかどうかを指定できる
- タグなしファイルを含める設定は初期状態でオフとする
- タグはフロントマター `tags` から読み取る
- タグの並び順は名前順とする
- Main側の構造化入力では、各タグ内の並び順としてファイル名順・更新日時順を受け付ける
- ファイル名順は拡張子を除いた表示名の昇順、更新日時順は新しい順とする
- 同じファイル名のMarkdownがワークスペース内に1つだけの場合は、拡張子を除いたファイル名だけの短い内部リンクにする
- 同じファイル名のMarkdownがワークスペース内に複数ある場合は、`[[./フォルダ/ファイル名|ファイル名]]` のようにワークスペースルートからのパスを含め、対象ファイルを一意に指すリンクにする
- リンクの表示名は、拡張子を除いたファイル名だけを使う
- Main側の構造化入力では出力先フォルダとファイル名を指定できる。通常操作ではワークスペースルートと既定名を使う
- 出力ファイル名が空の場合は、既定名「タグ別索引」を使う
- 出力先に同名ファイルが存在する場合は、別名で新規作成する
- 読めないMarkdownファイルがある場合は、その候補だけを除外して続行する
- 対象フォルダ自体が読めない場合は、安全側で処理を失敗させる

## 共通の実行条件

- 対象機能は上記の4種類とする
- ファイル加工は独立したビューやパネルを持たず、左レールまたはサイドバー内の対象を右クリックして「ファイル加工」サブメニューから実行する
- 左レール下部の登録済みワークスペース項目では、現在選択中のワークスペース全体のMarkdownを対象にする
- 選択中でない登録済みワークスペースの加工は無効にし、そのワークスペースへ切り替えてから実行するよう案内する
- フォルダでは子フォルダを含む配下のMarkdownを対象にする
- 右クリックした項目を含む2件以上のMarkdownファイルを複数選択している場合は、その選択ファイルだけを対象にする
- 単一Markdownファイルでは加工メニューを表示しない
- フォルダ、画像、PDFなどが混在する複数選択では加工を無効にし、Markdownファイルだけを選択する案内を表示する
- 対象の優先順位は、有効な複数選択、右クリックしたフォルダ、左レール下部の選択中ワークスペース項目の順とする
- 各実行アクションは設定確認を挟まず既定値を使い、ワークスペースルートへ新規Markdownファイルを作成する
- 通常操作の既定値は、タイトル一覧・目次・タグ別索引がファイル名順、タグ別索引がタグなしを除外、フォルダ内マージが絞り込みなし・ファイル名順・ファイル名見出しありとする
- 実行中は加工操作の重複開始を防ぎ、成功または失敗をトースト通知で示す。成功時は生成したMarkdownファイルを開く
- 対象になるMarkdownがない場合は失敗として通知し、空の出力ファイルを作成しない
- Rendererから渡された対象は、Main側でワークスペース境界、実体パス、Markdown種別、重複、件数、合計サイズを再検証する
- 1回の加工で扱える対象は最大10,000件、対象Markdownの合計サイズは100MiBまでとする。超過した場合は読み取りや出力を開始せず失敗として通知する
- マージの絞り込みとタグ別索引で本文を読む場合は、1ファイル4MiB、読み取り合計64MiBを上限とする。上限を超えた場合は加工全体を失敗させ、部分的な出力を作成しない
- 追加の加工ツールを検討する場合も、この仕様とは別作業として扱う
- 新しい加工ツールを追加する際も「既存ファイルを変更しない」原則を守ること
- 既定名補完後の出力ファイル名は、パス区切り、絶対パス、`.`、`..`、空の名前を受け付けない
- 出力ファイル名に `.md` が含まれる場合も、Markdownファイルとして扱い、必要に応じて末尾を `.md` にそろえる
- 出力先フォルダ、対象フォルダ、フォルダ絞り込みは、空文字または正規化済みのワークスペース相対パスだけを受け付ける
- 出力先がワークスペース外の実体を指すシンボリックリンクの場合は保存しない
- 出力先に同名候補が大量に存在する場合、無制限に候補探索を続けずエラーとして停止する
- 出力保存は安全書き込みで行う
